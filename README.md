# SerialMate 串口助手

SerialMate 串口助手是一款轻量、原生的 Windows 串口调试工具。程序使用 Win32 API 和 C++17 实现，不依赖 .NET 或第三方运行库；Release 版本静态链接 C/C++ 运行时，可直接复制运行。

## 功能

- 扫描并打开 COM 端口，使用 Windows SetupAPI 显示 `COMx + 设备名称`（例如 `COM7   USB-SERIAL CH340`），支持常见波特率、数据位、停止位、校验位和 RTS/CTS 流控。
- 文本编码可选 UTF-8（推荐）、GBK 或严格 ASCII；HEX 发送始终直接使用原始字节，CR、LF、CRLF 可独立组合。
- 定时发送，间隔范围 20 ms～3,600,000 ms。
- 定时发送遇到编码错误、内容错误、发送队列满或串口不可用时自动停用并只提示一次，修正后可重新启用。
- 加载文本文件到数据发送编辑框，可继续编辑后按当前文本编码或 HEX 模式发送。
- RX/TX 方向、毫秒时间戳、HEX 与 TEXT 双列记录（按当前编码解释，控制或不可解码字节显示为 `.`）、按窗口宽度选择 16/12/8/4 字节每行、暂停显示、清空、导出及六种复制方式。
- “实时记录”以固定的时间戳、RX/TX 方向和十六进制字节持续追加到文本文件；“启动日志”使用独立异步线程保存结构化日志。
- 日志、实时记录、串口发送队列和 UI 接收队列均有明确上限，溢出会提示而不会静默发生。
- 无配置文件、无注册表持久化；每次启动均采用固定默认值，发送输入框保持为空。
- 支持新建窗口和多个进程同时运行；同一串口仍遵循 Windows 独占访问规则。
- USB 串口异常时取消未完成 I/O、恢复未连接状态，并允许设备重新扫描后再连接。
- 启动后后台依次检查 Gitee、GitHub 更新清单；确认后可下载、校验 SHA-256 并由临时更新器安全替换 EXE。网络失败静默跳过，退出时立即取消请求。

## 快速使用

1. 运行 `SerialMate.exe`。
2. 在“串口号”中选择设备，按需要设置“文本编码（发送/显示）”，配置通信参数并点击“打开串口”。
3. 在“数据发送”中输入文本，按 Enter 或点击“发送”。需要在内容中插入换行时使用 Shift+Enter。
4. 二进制数据勾选“十六进制发送”；编辑框会自动清理、大写并格式化为 `FF FE 01 02` 形式，发送前会再次校验完整字节。
5. 点击“启动日志”保存结构化日志；点击“实时记录”选择文件后开始持续记录收发时间戳、方向和 HEX 数据；点击“导出...”保存当前通信记录。

默认日志与 EXE 位于同一目录。若程序放在无写权限目录，日志写入会失败，建议放在普通用户可写目录。
